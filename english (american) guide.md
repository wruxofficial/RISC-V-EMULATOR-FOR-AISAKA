# How to configure this module and emulator
It’s pretty easy—the structure should look like the photo <img width="248" height="197" alt="image" src="https://github.com/user-attachments/assets/7a680153-6d24-4c8d-91ff-5d3687d45966" />

Then launch the game to make sure it works. You don’t need to download this emulator from the releases; you can download the source code and create a module script in ReplicatedStorage, naming it as shown in the photo, and create a local script in StarterPlayerScripts, keeping the name LocalScript or choosing any other name you like.
